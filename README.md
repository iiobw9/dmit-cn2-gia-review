## 核心线路质量：CN2 GIA 和 CMIN2 有什么区别

这两条线路经常被混淆，简单说一下：

**CN2 GIA**（Global Internet Access）是电信的顶级商用线路，去程回程都走 CN2，国内三网（电信/联通/移动）访问都有优化，高峰期丢包率低。DMIT 香港和日本节点主打这条线路。

**CMIN2** 是移动的国际精品网，主要优化移动用户的访问体验，去程走 AS58453，回程走 CMIN2。DMIT 洛杉矶部分套餐走这条线路。

我自己测试香港 CN2 GIA 节点，工作日白天 ping 值在 30ms 左右，晚高峰也没有明显劣化。这个表现在同价位里算是比较稳的。
